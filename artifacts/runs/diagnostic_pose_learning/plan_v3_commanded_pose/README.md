# E3：速度命令＋末端目标方法比较

世界系EE-only经过连续1000轮课程仍有持续折足与支撑转换失败；同起点单项折足惩罚没有提供一致收益，故进入已授权的B路线。A路线及其结果保留。

新Actor输入279维，仍统一输出18个关节位置目标。末端任务系的原点为当前base XY及固定地面Z，旋转仅跟随base yaw；不跟随机身高度、roll、pitch。速度命令为yaw系vx/vy/yaw变化率，仿真来自预设轨迹，以后遥操作来自操作员。

28条60秒训练轨迹组合neutral/low/high/lateral与stand/forward/backward/left/right/yaw/arc；站立与移动组采样30/70。前2秒保持，命令8秒达设定值、末端20秒到端点。端点由原训练几何按本坐标定义转换，没有复用世界远距平移来制造不可达的相对目标。dev8复用训练来源，仅作开发读出。

从新策略开始：确定性均值输出q0，腿/臂初始目标角std为0.1/0.02rad，固定std；初始学习率1e-4、反馈下限1e-7。保留已有PPO、PD、UMI位姿奖励和支撑项，增加线速度/yaw跟踪峰值2/1；旧TCP速度与progress权重明确为0。训练配置有多项变化，属于方法配方比较，不归因为额外3个输入。

先验证CPU合同、初始双引擎站立20秒及64环境2轮训练入口，再以fresh 4096环境连续1000轮学习；预计9830万交互与20000次更新，实际数值另报。在250/500/1000开发读出，遇到真实持续崩坏或内部错误保存完整更新后停止。临时参数、未设正式朝向/速度阈值，所有bundle均trained=false。当前真实运行结果待写入。
