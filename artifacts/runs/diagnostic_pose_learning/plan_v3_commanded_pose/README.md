# E3：速度命令＋末端目标方法比较

世界系EE-only经过连续1000轮课程仍有持续折足与支撑转换失败；同起点单项折足惩罚没有提供一致收益，故进入已授权的B路线。A路线及其结果保留。

新Actor输入279维，仍统一输出18个关节位置目标。末端任务系的原点为当前base XY及固定地面Z，旋转仅跟随base yaw；不跟随机身高度、roll、pitch。速度命令为yaw系vx/vy/yaw变化率，仿真来自预设轨迹，以后遥操作来自操作员。

28条60秒训练轨迹组合neutral/low/high/lateral与stand/forward/backward/left/right/yaw/arc；站立与移动组采样30/70。前2秒保持，命令8秒达设定值、末端20秒到端点。端点由原训练几何按本坐标定义转换，没有复用世界远距平移来制造不可达的相对目标。dev8复用训练来源，仅作开发读出。

从新策略开始：确定性均值输出q0，腿/臂初始目标角std为0.1/0.02rad，固定std；初始学习率1e-4、反馈下限1e-7。保留已有PPO、PD、UMI位姿奖励和支撑项，增加线速度/yaw跟踪峰值2/1；旧TCP速度与progress权重明确为0。训练配置有多项变化，属于方法配方比较，不归因为额外3个输入。

先验证CPU合同、初始双引擎站立20秒及64环境2轮训练入口，再以fresh 4096环境连续1000轮学习；实际98,304,000次交互与20,000次更新，已退出0。在250/500/1000开发读出，遇到真实持续崩坏或内部错误保存完整更新后停止。临时参数、未设正式朝向/速度阈值，所有bundle均trained=false。初始／最终双引擎开发与独立测试读出均已完成。

## 实际启动记录

集成CPU148项通过、独立只读审查无阻断finding；初始两引擎stand20和MuJoCo dev8实际退出0。初始stand位置RMSE：PhysX6.79cm、MuJoCo10.10cm，均完整且未跌倒；但MuJoCo从7.88s出现后大腿真实地面接触，不能称干净支撑，world接触列已从机器人非足统计中排除。64环境2轮PPO实际退出0，3072交互、40更新、全部有限、零跌倒；其权重未用于主训练。fresh4096环境连续1000轮已实际退出0；[training_summary.json](training_summary.json)记录98,304,000次交互、20,000次更新，全部有限，3987次跌倒／33,627次重置，训练循环3651.53秒。最终权重为`train1000/checkpoint_000999.pt`，完整1000轮bundle为`train1000/bundle`；训练完成不证明任务学会。

## 连续训练首个开发读出：checkpoint250（实际251轮）

CPU导出及MuJoCo dev8完整评估实际退出0：6/8完整，low_stand19.22s跌倒，neutral_yaw53.48s跌倒。完整neutral_forward命令速度RMSE.1930m/s，接近.2m/s设定值，尚无有效前进；完整high_stand/lateral_stand位置RMSE.7647/.7025m、朝向1.4067/2.4401rad。低位短片段不能与完整初始60s直接比较来声称改善。

保存轨迹全FK复核8例通过，最大TCP误差4.86e-8m；各例未见足底高于同侧thigh，但high与neutral_left有非足净力，且上述跌倒和大误差仍在。这不是全身协同成功。主训练仍连续运行，等后续检查点判断趋势，不根据单个开发检查点切换方法。

## 第二个开发读出：checkpoint500（实际501轮）

CPU导出、MuJoCo dev8与保存状态支撑复算均实际退出0，8/8完整60s无配置跌倒；这恢复了初始策略也具备的运行完整性。独立只读复核稳定命令段：forward要求.2m/s、实际均vx约.0063；left要求.12m/s、实际vy约−.0005；yaw要求.3rad/s、实际yawdot约.0066。命令基本未执行。low完整保持段位置/朝向由初始.602m/2.075rad至.487m/1.799rad，有局部改善，但high与lateral退步。250的low没有保持窗，不能用短片段均值比较。

FK最大TCP误差5.51e-8m，各例仍无足底高于同侧thigh；但neutral_forward非足净力>5N约55.3%，基座post2中位高度.171m，low高度.152m接近既有.15m终止线。完整运行不代表合理任务支撑。当前证据为两项能力均不足，未定位出普通PPO只顾一项的优势分配冲突，不据此启动E4。该阶段随后继续到已定1000轮预算，最终结论见下。

最终PhysX／MuJoCo dev8均7/8完整60秒，失败分别为neutral_left 46.74秒／neutral_forward 35.54秒。完整稳定命令窗中，PhysX forward实际vx为−.000555m/s、yaw实际变化率为.00410rad/s，对应命令为.20m/s／.30rad/s；MuJoCo left实际vy为−.000652m/s、yaw为−.000498rad/s，对应.12m/s／.30rad/s。移动命令仍基本未执行。末端完整保持窗中，PhysX low/high/lateral/arc位置RMSE为.602/.893/.860/.821m，MuJoCo为.530/.909/.858/.842m；不能用混合训练误差替代这些任务结果。

PhysX开发集7个完整回合在post20支撑采样中均四足>1N、没有非足净力>5N；low平均base高度.220m（neutral为.305m），说明出现有足支撑的身体降低，但该例末端误差.602m／2.051rad，不证明完成任务所需的主动下蹲。MuJoCo独立test8仅high_stand完整，其末端保持误差.81149m／1.29335rad，post20非足净力>5N占94.90%；另外7例跌倒，不能把存活等同于干净支撑。净接触力不区分地面与自碰撞。支撑采样使用poststate20..60秒，误差保持窗使用target20..59.98秒，两者不混作同一采样窗。

PhysX独立test8的4个完整案例为low_forward、high_stand、middle_backward、middle_right；末端保持位置RMSE分别为.9784/.73964/.79629/.33936m，朝向为2.6225/1.21183/2.81350/2.68576rad。forward实际vx为−.001368m/s（命令+.18），backward为+.002036（命令−.12），right实际vy为−.000489（命令−.10）。跌倒案例为low_stand17.76秒、high_yaw10.58秒、lateral_left10.30秒、lateral_arc14.84秒。middle_right虽存活，但post20非足净力>5N占100%、平均高度.1873m；high_stand未记录该非足接触，但没有四足同时>1N的采样。另两个完整案例四足承重且没有该非足接触，也未完成命令与末端任务。

误差保持窗和稳定命令窗只有实际完整且未跌倒才作为完整窗口报告；失败片段单列，不混入一个均值制造改善。最终支撑FK最大TCP重建误差：PhysX开发／独立测试3.49e-6／3.44e-6m；这验证保存状态读出的几何一致性，不证明姿态合理。

**结论与下一步边界**：此单种子1000轮方法配方未学会有效命令移动与一般化末端操作，不采用为全身控制成果；不证明额外速度输入无用，也不足以排除更长训练或不同配方的收益。当前不是“普通PPO仅学会一项”的清晰证据，不自动触发E4 Advantage Mixing；未选出可用方案，不进入E5正式多种子统计，不原样追加预算。A世界系EE-only及历史E0／E1／E2／折足结果保留。低／高／侧／远目标、变化朝向下的任务驱动下蹲、倾身、支撑转换、腿臂补偿与移动视觉闭环仍未完成；原任务验收值保持，朝向／速度正式阈值未指定，临时参数与`trained=false`边界不变。
