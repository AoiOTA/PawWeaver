# PawWeaver：当前目标与推进依据

以用户明确的全身控制能力目标和实际证据推进。《AS2 EDU + Piper-H 全身协同移动操作仿真方案》提供架构、场景和验证思路的参考；不要求逐条恢复全部模块、按固定阶段顺序执行或重做已经完成的工作。具体实验记录见 [runbook](runbook.md)，数值评价和证据边界见 [validation](validation.md)。

## 当前明确的能力目标

同一个强化学习 Actor 仅根据固定任务／世界系末端位置、朝向目标及本体观测，统一输出12腿＋6臂关节目标。机器人为了完成末端任务，自主协调机械臂、身体姿态与支撑：需要时下蹲、倾身、升降身体、转身和迈步；原地全身仍够不到时，稳定地移动过去完成任务。目标不随基座移动而重新锚定，不输入外部底盘速度命令或手写步态。

既要能到达给定目标，也要能持续跟踪移动目标。训练轨迹应广泛覆盖组合机器人的操作空间，并包含需要移动支撑位置的目标。18维动作、训练有限、局部误差下降或基座移动均不单独证明上述能力；需要结合TCP误差、腿臂动作、身体运动和足端接触判断。

已有方向保持：Isaac Lab训练，独立MuJoCo验证同一策略，状态控制稳定后接入图像测量驱动的目标。D435替代DC1已获授权；第一版仍为固定开度夹爪，保留负载，不加入抓取接触、力控制、复杂地形和真机部署。

## 参考与可调整内容

- 原plan中关于世界系目标、全身任务驱动、分层排查Sim2Sim、接触与负载、独立测试的思路继续参考。
- 原plan的课程安排、MLM模块、预测器、速度估计器、示范数据和自适应采样是可选技术路径；按当前缺口和实测收益选择，不为完成清单而全部实现。
- 用户举例的空间盒、时间范围、人手速度及随机路点／minimum-jerk方法不是规定方案。采样、插值、奖励配方、并行规模和预算都是需要实际检验的工程选择。
- UMI实测数据不是当前依赖。已有可靠实现和证据继续复用；未标定的外部位姿不冒称本机器人原生TCP示范。
- 临时动力学参数允许已授权工程实验继续，但结果不能建立硬件有效性；不把参数未闭合用作停止所有学习工作的理由，也不把工程成功写成正式硬件验收。

## 沿用的评价基线与交付方向

保留既有评价数值用于连续比较，不因当前实验容易通过而放宽：静态目标水平距离约0.3–2m，10秒内到达5cm并保持1秒、成功率95%；连续目标速度不超过0.3m/s、完整60秒、过渡后位置RMSE不超过8cm／P95不超过15cm、至少95%回合无跌倒。原跨引擎参考规模为每引擎至少100回合、3个训练种子，到达成功率下降不超过10个百分点。小规模单种子诊断不冒充该规模；新增朝向正式阈值尚未确定。

完整时长和提前终止必须分别报告；前后误差按共同时间窗比较，不能让提前跌倒后的短均值制造改善。视觉测量误差、失跟和恢复另行评分，目标真值不进入视觉控制输入。新增方法只有实测带来任务收益才值得采用。

交付围绕可复现配置、资产、检查点、独立推理、测试结果与能展示实际全身行为的视频展开，具体实现随证据调整。当前全身移动操作能力尚未完成。

KMA同样以实际效果检验：是否帮助选对下一步、合理分工并暴露失败。只修观察到的问题；规则数量、安装、代理数量和软件检查不代表有效性。
